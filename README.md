# 📚 Ejercicios de Listas - Clase 29/04

¡Hola! 👩‍🏫 En esta oportunidad quiero compartir con ustedes una serie de ejercicios prácticos sobre **listas** que vimos en clase el **29 de abril**.

### 📌 Contenido del repositorio

1. **Sintaxis y operaciones básicas con listas**
   - Ejercicios para que puedan ver **cómo crear, acceder y modificar listas** en Python.
   - Es ideal para afianzar la base antes de pasar a ejercicios más complejos.

2. **Slicing y manipulación de listas**
   - Actividades para que entiendan cómo funciona el **slicing** y cómo recorrer listas usando distintas técnicas.
   - Incluye ejemplos para practicar extracciones, reemplazos y combinaciones.

3. **Uso de `split()` y conversión de cadenas**
   - Casos donde trabajamos con texto y lo transformamos en listas usando la función `split()`.
   - Les ayudará a entender cómo convertir datos y prepararlos para su procesamiento.

4. **📄 PDF con ejercicios nuevos**
   - Incluye un **nuevo conjunto de ejercitaciones sobre listas y bucles**, pensado para seguir practicando y consolidar lo aprendido.
